# 🌟 Curated ML Resources

## 📖 Books
| Book | Level | Why |
|---|---|---|
| *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* — Aurélien Géron | Beginner→Intermediate | Best practical all-rounder |
| *An Introduction to Statistical Learning (ISL)* — James, Witten, Hastie, Tibshirani | Beginner | Free PDF, intuition first |
| *The Elements of Statistical Learning* — Hastie, Tibshirani, Friedman | Advanced | Free PDF, rigorous reference |
| *Pattern Recognition and Machine Learning* — Bishop | Advanced | Probabilistic view |
| *Deep Learning* — Goodfellow, Bengio, Courville | Intermediate | Free online, DL theory |
| *Dive into Deep Learning* — Zhang et al. | Beginner→Intermediate | Free, runnable code (d2l.ai) |
| *Mathematics for Machine Learning* — Deisenroth, Faisal, Ong | Beginner | Free PDF, the math you need |
| *Designing Machine Learning Systems* — Chip Huyen | Intermediate | Production ML |
| *Introduction to Machine Learning with Python* — Müller & Guido | Beginner | Source of the NumPy/pandas style used here |
